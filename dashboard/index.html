How implied value is computed

One function scores every row. No protocol name is special-cased, no row is hand-picked, and every number below is computed from the snapshot — the dashboard renders the same figures from data.js.

ln(market cap) = 7.918 + 0.460 × ln(TVL) + category adjustment  ·  implied = exp(...) × quality  ·  band = base × e±2.11

  • 128 comps. The regression learns from the 128 protocols that already have a token and a TVL above zero. Slope 0.460, intercept 7.918, residual σ 2.111, R² 0.265. A slope below 1 means market cap grows slower than TVL: ten times the TVL is worth about three times the value.
  • 13 category adjustments. Lending is the reference (15 comps, adjustment 0). Privacy +1.39 (3), Basis Trading +1.23 (7), CEX +1.04 (9), Canonical Bridge +0.92 (8), Cross Chain Bridge +0.76 (4), RWA +0.34 (9), Dexs +0.23 (11), Bridge +0.05 (6), Indexes +0.04 (3), Yield −0.62 (9), Liquid Staking −0.80 (9), Yield Aggregator −0.98 (4), CDP −1.02 (3). 227 rows use their category's adjustment.
  • 115 rows fall back to the median. A category earns its own intercept only with at least 3 tokenized comps behind it — one protocol cannot set a category's multiple. Those rows use the snapshot's overall upper-median market-cap/TVL of 0.223×. Each detail view says which of the two its row used and how many comps back it.
  • Quality factors. Growth clamps 1 + change_7d/100 to 0.8–1.25; breadth is min(1 + 0.02 × (chains − 1), 1.2); age is 0.9 when listed under 90 days, else 1. Implied value is the regression base times their product, rounded to the dollar.
  • Blind test: typical miss ×5.72. The comps are split in half by slug; the model fits the first 64 and predicts the second 64, using the same fallback rule. Typical (geometric-mean) miss ×5.72, median miss ×4.49. The band on every row says the same thing in dollars: the honest answer is a range, not a point.
  • Farm economics. Expected airdrop = base × 5% × (capital / TVL) × 20. Cost = gas on the protocol's cheapest chain + 2% opportunity cost on the capital. Capital is $250 / $150 / $100 / $50 by TVL tier; hold is 60 / 45 / 30 days by age. Verdict: farm when expected is at least 3× cost (164 rows), thin when at least 1× (129), skip below that (49).
  • What the board covers. 758 protocols in the snapshot, 342 pre-token scored, 40 of them on the $50M-TVL watchlist — all 40 covered. The 416 protocols that already have a token are set aside; their market caps are the comps the model learns from. Median row: $17.0M TVL, $7.4M implied.

Implied value is a model, not a price. It is the value a token would have if this protocol were priced like the average protocol in its category — nothing more.
